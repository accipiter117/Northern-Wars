# Northern Wars

A mobile-first browser kingdom simulator set in the world of The Witcher. You are the crown of Temeria. Fan project: original code and placeholder art only.

- Play: open `index.html` through any static server, for example `npm run serve` then http://127.0.0.1:8765/
- Tests: `npm ci` then `npm test`
- Balance: see [docs/BALANCE.md](docs/BALANCE.md); `node tools/longrun.mjs 30 steward` plays thirty years, `node tools/lawbalance.mjs` compares every law option
- `?nohints` in the address turns tutorial hints off (the smoke tests use it)
- Working rules: [CLAUDE.md](CLAUDE.md). Design: [docs/DESIGN.md](docs/DESIGN.md). Milestones: [docs/ROADMAP.md](docs/ROADMAP.md).
